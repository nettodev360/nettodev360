# Hi, I'm Michael Netto 👋

AI & Operations Coordinator at Upper Canada College (Pickering / Toronto, Ontario). I help people work smarter with AI — and I build AI systems that work for them.

### How I build — "vibe coding"
I build production-ready tools using AI-assisted development. My approach: I prompt — then AI builds. I review, refine, and refactor the code. Then I ship it.

My work spans Google Workspace automation, Notion, Airtable, Claude, ChatGPT, Gemini, Replit, Claude Code, Bolt, Lovable, GitHub Copilot, and custom AI agents — turning repetitive tasks into intelligent systems.
